# 상식 퀴즈 게임 PRD

작성일: 2026-10-26 · 수정일: 2026-10-27 (점수 시스템, 게임 모드 3종, 힌트 추가)

## 1. 개요

한국사·과학·지리·일반상식 4개 카테고리, 총 40문제의 4지선다 상식 퀴즈 웹 게임이다(화면 타이틀 'QUIZ SHOW'). 플레이어는 게임 모드를 골라 문제를 풀고, 문제마다 정답 여부와 얻은 점수를 바로 확인한다. 게임이 끝나면 점수를 모드별 순위표에 기록해 다른 기록과 비교한다.

- 대상 사용자: 짧은 시간에 상식을 점검하고 싶은 일반 사용자, 친구와 점수를 겨루려는 사용자
- 핵심 목표: (1) 끊김 없는 퀴즈 진행, (2) 문제마다 즉시 정답/오답·득점 피드백, (3) 난이도·속도·연속 정답을 반영한 점수와 모드별 순위

## 2. 범위와 전제

서버 없이 브라우저에서 돌아가는 단일 페이지 웹 게임이다. 문제 데이터는 JS 파일에 넣고, 기록과 틀린 문제 목록은 브라우저 localStorage에 저장한다.

| 항목 | 내용 |
| --- | --- |
| 플랫폼 | 데스크톱·모바일 웹 브라우저 (Chrome, Edge, Safari 최신 버전) |
| 기술 스택 | HTML, CSS, 순수 JavaScript (프레임워크·빌드 도구 없음) |
| 데이터 저장 | 문제: `questions.js`, 기록·틀린 문제: localStorage |
| 실행 방법 | `index.html`을 브라우저로 열면 바로 실행 |

**포함 범위**

- 4개 카테고리 × 10문제 = 40문제, 문제마다 난이도(easy/medium/hard)
- 게임 모드 3종(전체도전, 카테고리별, 스피드퀴즈)과 틀린 문제 복습
- 난이도 배수와 보너스(시간, 힌트 미사용, 연속 정답)를 반영한 점수
- 힌트(50:50): 오답 보기 2개 지우기
- 문제별 즉시 피드백, 결과 화면, 오답 노트, 모드별 상위 10개 순위표

**제외 범위 (이번 버전에서는 만들지 않음)**

- 회원가입·로그인·닉네임, 서버 DB, 온라인 공유 순위표
- 효과음·배경음
- 문제 편집용 관리자 화면

## 3. 게임 모드와 사용자 흐름

| 모드 | 문제 | 순서 | 제한 시간 | 순위표 |
| --- | --- | --- | --- | --- |
| 전체도전 (ALL CHALLENGE) | 4과목 40문제 | 과목 탭(한국사 → 과학 → 지리 → 일반상식), 탭을 눌러 과목을 오갈 수 있음 | 문제당 15초 | 전체도전 |
| 카테고리별 (CATEGORY) | 고른 과목 10문제 | 과목 안에서 출제 순서 규칙(F-02) | 문제당 15초 | 카테고리별 (과목 함께 표시) |
| 스피드퀴즈 (SPEED QUIZ) | 40문제 중 무작위 20문제 | 과목을 섞어 무작위 | 문제당 15초 | 스피드퀴즈 |
| 틀린 문제 복습 | 틀린 문제 목록 전체 | 카테고리 순서 | 문제당 15초 | 기록하지 않음 |

**규칙**

- 문제마다 보기 4개 중 1개를 고른다. 한 번 고르면 바꿀 수 없다.
- 고르는 즉시 정답/오답과 득점 내역을 보여주고, '다음' 버튼을 눌러야 다음 문제로 넘어간다.
- 모든 모드에서 문제당 15초 안에 답하지 않으면 시간 초과로 오답 처리한다.
- 끝까지 푼 판만 그 모드의 순위표에 기록한다. 중간에 그만둔 판과 복습은 기록하지 않는다.
- 순위는 점수가 높은 순, 점수가 같으면 소요 시간이 짧은 순, 그것도 같으면 먼저 기록한 순이다.

**점수 규칙** (맞힌 문제만 득점)

| 항목 | 점수 |
| --- | --- |
| 기본 점수 | 10점 × 난이도 배수 (easy ×1 = 10, medium ×1.5 = 15, hard ×2 = 20) |
| 시간 보너스 | 문제를 띄운 뒤 10초 미만에 맞히면 +3 |
| 힌트 미사용 보너스 | 그 문제에서 힌트를 쓰지 않고 맞히면 +2 |
| 콤보 보너스 | 연속 정답 3개째 +2, 5개째 +5, 10개째 +10 (도달한 그 문제에서 한 번씩) |

- 틀리거나 시간 초과면 0점이고 연속 정답이 0으로 돌아간다.
- 문제 시간은 문제마다 따로 잰다. 전체도전에서 다른 과목 탭으로 옮기면 시간이 멈췄다가 돌아오면 이어서 잰다. 그만두기 확인 창이 떠 있는 동안에도 멈춘다.
- 연속 정답은 과목 탭과 관계없이 답한 순서대로 센다.

**사용자 흐름**

1. 시작 화면에서 모드를 고른다. 카테고리별은 과목 버튼을 누르면 바로 시작한다.
2. 퀴즈 화면에서 문제를 읽고, 필요하면 50:50 힌트를 쓴 뒤 보기 하나를 누른다.
3. 피드백(정답 여부, 득점 내역, 해설)을 보고 '다음'을 누른다.
4. 전체도전에서 과목이 끝나면 그 과목 맞힌 수(예: 한국사 7/10)를 짧게 보여준다.
5. 마지막 문제 후 결과 화면에서 총점, 정답 수, 과목별 맞힌 수, 점수 항목별 합계, 최고 콤보, 소요 시간, 순위를 본다.
6. 기록은 자동 저장되고, '다시 하기', '틀린 문제', '순위표'를 고른다.

## 5. 데이터 구조

문제는 카테고리 키로 묶인 배열이고, `answer`는 셔플 전 `choices` 배열의 인덱스(0~3)다. 보기를 섞을 때는 정답 문자열을 기준으로 새 정답 인덱스를 다시 계산한다.

**문제 데이터 (`questions.js`)**

```javascript
const QUESTIONS = {
  history: [
    {
      id: "h06",
      difficulty: "easy",        // "easy" | "medium" | "hard"
      year: 1446,                // 한국사만: 시대순 정렬용
      question: "훈민정음을 반포한 조선의 왕은?",
      choices: ["태조", "세종", "정조", "영조"],
      answer: 1,
      explanation: "세종은 1446년에 훈민정음을 반포했다."
    }
    // ... 10문제
  ],
  science: [ /* 10문제 */ ],
  geography: [ /* 10문제 */ ],
  general: [ /* 10문제 */ ]
};

const CATEGORIES = [
  { key: "history", name: "한국사", chronological: true },
  { key: "science", name: "과학" },
  { key: "geography", name: "지리" },
  { key: "general", name: "일반상식" }
];
```

난이도는 과목마다 easy 4 · medium 3 · hard 3으로 나눈다.

**기록 데이터 (localStorage 키: `quiz-records-v2`)**

점수 규칙이 바뀌어 예전 기록(`quiz-records`, 1문제 1점)과 키를 나눴다. 예전 기록은 읽지 않는다.

```javascript
[
  {
    id: "1761482400000",
    mode: "category",          // "all" | "category" | "speed"
    category: "geography",     // 카테고리별일 때만, 나머지는 null
    score: 187,
    correct: 9,
    total: 10,
    maxCombo: 6,
    categoryScores: { geography: 9 },
    elapsedSec: 95,
    playedAt: "2026-10-27T21:40:00+09:00"
  }
]
```

**틀린 문제 (localStorage 키: `quiz-wrong`)**: 문제 id 배열

**게임 진행 상태 (메모리, 저장 안 함)**

```javascript
const state = {
  mode: null,          // "all" | "category" | "speed" | "review"
  category: null,      // 카테고리별에서 고른 과목
  sessions: [],        // 과목 탭마다 { key, name, queue, index, correct, points,
                       //   picked, removed, spentMs, shownAt, result }
  current: 0,
  categoryScores: {}, categoryTotals: {},
  combo: 0, maxCombo: 0,
  breakdown: { base: 0, fast: 0, noHint: 0, combo: 0 },
  startedAt: null, endedAt: null, quit: false,
  wrongAnswers: []
};
```

순위 정렬은 `records.sort((a, b) => b.score - a.score || a.elapsedSec - b.elapsedSec || a.playedAt.localeCompare(b.playedAt))`로 처리한다. localStorage 읽기·쓰기는 try/catch로 감싸고, 실패하면 빈 배열로 시작한다.

## 6. 화면 구성

화면은 5개이며, 한 HTML 안에서 `section`을 숨기고 보이는 방식으로 전환한다. 시작·틀린 문제·순위 화면 위에는 메뉴 탭(QUIZ · WRONG ANSWERS · RANKING)이 있다.

| 화면 | 구성 요소 | 이동 |
| --- | --- | --- |
| 시작 | 전구 간판 타이틀, ALL CHALLENGE 버튼, CATEGORY 과목 버튼 4개, SPEED QUIZ 버튼, 점수 규칙(SCORING, 접힘) | 모드 → 퀴즈 |
| 퀴즈 | 상단: QUESTION 간판, 그만두기, 과목 탭(전체도전만), 과목·난이도·문제 번호·콤보·점수, 진행 바, 시간 게이지 · 중앙: 질문, 힌트 버튼("HINT!"), 보기 4개 · 하단: 피드백·득점 내역·해설, '다음' | 마지막 '다음' → 결과 |
| 결과 | 모드 이름, 총점(정답 수 · 정답률), 과목별 맞힌 수, 점수 항목별 합계와 최고 콤보, 소요 시간, 순위 안내, 오답 노트, '다시 하기'·'틀린 문제'·'순위표' | 다시 하기 → 시작 |
| 틀린 문제 | 틀린 문제 목록, '다시 풀기', '목록 비우기' | 다시 풀기 → 퀴즈 |
| 순위 | 모드 탭 3개, 모드별 규칙 안내, 순위·(과목)·점수·정답 수·소요 시간·날짜 표(상위 10개), 방금 기록 강조, '처음으로', '기록 초기화' | 처음으로 → 시작 |

문제 시간은 진행 바 바로 아래의 같은 모양 게이지로 보여주며, 숫자 없이 왼쪽에서 오른쪽으로 차오른다. 모든 모드에서 제한 시간 15초에 가득 차고, 시간 보너스 기준 10초를 넘기면(남은 5초) 붉게 바뀐다. 보기 버튼은 2×2로 배치하고 높이는 최소 48px로 한다.

## 7. 비기능 요구사항

- 성능: 보기를 누른 뒤 피드백이 0.1초 안에 표시된다.
- 호환성: 360px 폭 모바일부터 1920px 데스크톱까지 가로 스크롤 없이 표시된다.
- 접근성: 정답/오답을 색만이 아니라 "정답"/"내 답" 문구와 아이콘으로도 구분한다. 보기는 키보드 1~4 키로도 고를 수 있고, 힌트로 지운 보기는 키보드로도 고를 수 없다.
- 안정성: 문제 데이터가 카테고리별 10개가 아니거나, 보기가 4개가 아니거나, 난이도 값이 잘못되면 콘솔에 오류를 출력하고 시작 버튼을 막는다.
- 콘텐츠: 문제와 정답은 `CLAUDE.md`의 교차검증 규칙에 따라 출처 2곳 이상으로 확인하고 `questions-verification.md`에 기록한다.

## 8. 수용 기준

- [ ] 전체도전은 40문제, 카테고리별은 고른 과목 10문제, 스피드퀴즈는 20문제가 나온다.
- [ ] 두 번 플레이했을 때 문제 순서(한국사 제외)와 보기 순서가 달라진다.
- [ ] 오답을 고르면 고른 보기와 실제 정답이 구분되어 표시되고 해설이 보인다.
- [ ] 답한 뒤에는 다른 보기를 눌러도 점수가 바뀌지 않는다.
- [ ] hard 문제를 힌트 없이 10초 안에 맞히면 25점(20+3+2)을 얻는다.
- [ ] 힌트를 쓰면 정답이 아닌 보기 2개가 지워지고, 그 문제는 힌트 미사용 보너스를 받지 못한다.
- [ ] 연속 3·5·10번째 정답에서 콤보 보너스 +2·+5·+10이 붙고, 틀리면 연속 정답이 끊긴다.
- [ ] 모든 모드에서 15초가 지나면 시간 초과 오답으로 처리된다.
- [ ] 결과 화면의 총점이 점수 항목별 합계의 합과 같다.
- [ ] 끝까지 푼 판은 그 모드의 순위표에만 기록되고, 새로고침 후에도 남아 있다.
- [ ] 점수가 같은 두 기록은 소요 시간이 짧은 쪽이 위에 온다.

## 9. 열린 질문

- 나중에 순위표를 여러 기기에서 공유하려면 서버나 Firebase 같은 외부 저장소가 필요하다.
- 카테고리별 순위표는 과목을 섞어 한 표로 보여준다. 과목별로 나눌지는 플레이 기록을 보고 정한다.
