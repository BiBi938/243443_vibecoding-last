# 상식 퀴즈 게임 PRD

작성일: 2026-10-26
수정일: 2026-10-26 (과목별 풀기·문제 수 선택, 한국사 시대순 출제, 과목 탭 이동, 틀린 문제 탭 추가, 닉네임 입력 제거, 그만 풀기 추가, 레트로 TV 퀴즈 쇼 디자인 적용)

## 1. 개요

한국사·과학·지리·일반상식 4개 과목, 총 40문제의 4지선다 상식 퀴즈 웹 게임을 만든다. 플레이어는 과목 하나를 골라 원하는 문제 수만큼 풀거나, 모든 과목을 차례로 풀 수 있다. 문제를 풀 때마다 정답 여부를 바로 확인하고, 틀린 문제는 따로 모아 나중에 다시 푼다. 모든 과목을 정식 분량으로 푼 기록은 순위표에서 이전 기록과 비교한다.

- 대상 사용자: 짧은 시간에 상식을 점검하고 싶은 일반 사용자, 특정 과목만 골라 연습하려는 사용자
- 핵심 목표: (1) 과목·문제 수를 골라 바로 시작하는 퀴즈 진행, (2) 문제마다 즉시 정답/오답 피드백, (3) 틀린 문제 복습, (4) 점수 기록과 순위 표시

## 2. 범위와 전제

서버 없이 브라우저에서 돌아가는 단일 페이지 웹 게임으로 만든다. 문제 데이터는 JS 파일에 넣고, 점수 기록과 틀린 문제 목록은 브라우저 localStorage에 저장한다. 로그인이나 닉네임 입력 없이 바로 시작하며, 기록은 그 브라우저에만 남는다.

| 항목 | 내용 |
| --- | --- |
| 플랫폼 | 데스크톱·모바일 웹 브라우저 (Chrome, Edge, Safari 최신 버전) |
| 기술 스택 | HTML, CSS, 순수 JavaScript (프레임워크·빌드 도구 없음) |
| 데이터 저장 | 문제: `questions.js`, 기록·틀린 문제: localStorage |
| 실행 방법 | `index.html`을 브라우저로 열면 바로 실행 |

**포함 범위**

- 4개 과목 × 10문제 = 40문제
- 과목별 풀기(문제 수 1~10 선택), 모든 과목 풀기, 틀린 문제 다시 풀기의 3가지 모드
- 모든 과목 풀기 중 과목 탭으로 자유롭게 이동
- 문제별 즉시 피드백, 진행 상황 표시, 결과 화면과 오답 노트
- 틀린 문제 목록 저장과 복습
- 정식 게임(모든 과목 10문제씩) 기록 저장, 상위 10개 순위표

**제외 범위 (이번 버전에서는 만들지 않음)**

- 회원가입·로그인, 닉네임, 서버 DB, 온라인 공유 순위표
- 제한 시간, 난이도 선택, 효과음·배경음
- 문제 편집용 관리자 화면

## 3. 게임 규칙과 사용자 흐름

한 문제당 1점이다. 문제를 고르는 방식은 모드에 따라 다르다.

**모드**

| 모드 | 시작 방법 | 출제 | 순위표 기록 |
| --- | --- | --- | --- |
| 과목별 풀기 | 과목 버튼 → 문제 수 선택 → '○○ N문제 풀기' | 그 과목에서 N문제 | 기록 안 함 |
| 모든 과목 풀기 | '모든 과목 풀기' | 과목마다 각자 설정한 문제 수 (기본 10) | 4과목 모두 10문제(총 40문제)일 때만 기록 |
| 틀린 문제 다시 풀기 | 틀린 문제 탭 → '틀린 문제 다시 풀기' | 저장된 틀린 문제 전체 | 기록 안 함 |

**출제 순서**

- 한국사는 시대순(사건 연도 오름차순)으로 출제한다. 문제 수를 줄이면 무작위로 뽑은 뒤 시대순으로 정렬한다.
- 과학·지리·일반상식은 매 판 문제 순서를 무작위로 섞는다.
- 보기 순서는 모든 과목에서 매 판 무작위로 섞는다.
- 모든 과목 풀기와 틀린 문제 다시 풀기는 한국사 → 과학 → 지리 → 일반상식 순서로 진행한다.

**규칙**

- 문제마다 보기 4개 중 1개를 고른다. 한 번 고르면 바꿀 수 없다.
- 고르는 즉시 정답/오답을 보여주고, '다음' 버튼을 눌러야 다음 문제로 넘어간다.
- 모든 과목 풀기에서는 퀴즈 화면 위의 과목 탭을 눌러 언제든 다른 과목으로 옮겨 갈 수 있다. 과목마다 진행 상태(몇 번 문제까지 풀었는지, 답만 하고 '다음'을 누르지 않은 상태 포함)를 따로 기억하므로, 돌아오면 풀던 곳에서 이어진다. 다 푼 과목의 탭은 비활성화된다.
- 한 과목을 다 풀면 덜 푼 과목 중 고정 순서상 가장 앞 과목으로 넘어간다. 모든 과목을 다 풀면 결과 화면으로 간다.
- 퀴즈 중 언제든 '그만 풀기'로 끝낼 수 있다. 푼 문제가 없으면 바로 시작 화면으로 가고, 있으면 확인 창을 거쳐 지금까지 푼 문제만으로 결과를 보여준다. 그만둔 판은 순위표에 기록하지 않는다.
- 틀린 문제는 틀린 문제 목록에 저장되고, 어떤 모드에서든 그 문제를 다시 맞히면 목록에서 빠진다.
- 제한 시간은 없지만, 첫 문제부터 마지막 문제에 답할 때까지 걸린 시간을 측정한다. 과목 전환 안내가 떠 있던 시간은 빼고 잰다.
- 순위는 점수가 높은 순, 점수가 같으면 소요 시간이 짧은 순, 그것도 같으면 먼저 기록한 순이다.

**사용자 흐름**

1. 시작 화면에서 과목 버튼을 눌러 문제 수를 고르고 그 과목을 풀거나, '모든 과목 풀기'를 누른다.
2. 퀴즈 화면에서 문제를 읽고 보기 하나를 누른다. (모든 과목 풀기라면 과목 탭으로 다른 과목으로 옮겨 갈 수 있다.)
3. 피드백이 표시되면 '다음'을 누른다. 2~3을 반복한다.
4. 모든 과목 풀기에서 한 과목이 끝나면 그 과목 점수(예: 한국사 7 / 10)를 짧게 보여주고 다음 과목으로 넘어간다.
5. 마지막 문제 후 결과 화면에서 총점, 과목별 점수, 소요 시간, 순위(정식 게임일 때), 오답 노트를 본다.
6. '다시 하기', '틀린 문제', '순위표' 중 하나를 고른다.

## 5. 데이터 구조

문제는 과목 키로 묶인 배열이고, `answer`는 셔플 전 `choices` 배열의 인덱스(0~3)다. 보기를 섞을 때는 정답 문자열을 기준으로 새 정답 인덱스를 다시 계산한다. `chronological: true`인 과목은 `year` 오름차순(같으면 `id` 순)으로 출제한다.

**문제 데이터 (`questions.js`)**

```javascript
const QUESTIONS = {
  history: [
    {
      id: "h01",
      year: 372,            // 한국사만: 시대순 정렬용 사건 연도
      question: "삼국 가운데 가장 먼저 불교를 공식적으로 받아들인 나라는?",
      choices: ["고구려", "백제", "신라", "발해"],
      answer: 0,
      explanation: "고구려는 372년 소수림왕 때 전진에서 불교를 받아들였다. 백제는 384년, 신라는 527년에 불교를 공인했다."
    }
    // ... 10문제 (시대순으로 작성)
  ],
  science: [ /* 10문제 */ ],
  geography: [ /* 10문제 */ ],
  general: [ /* 10문제 */ ]
};

const CATEGORIES = [
  { key: "history", name: "한국사", chronological: true },
  { key: "science", name: "과학" },
  { key: "geography", name: "지리" },
  { key: "general", name: "일반상식" }
];
```

**기록 데이터 (localStorage 키: `quiz-records`, 정식 게임만)**

```javascript
[
  {
    id: "1761482400000",
    score: 34,
    categoryScores: { history: 9, science: 8, geography: 7, general: 10 },
    elapsedSec: 412,
    playedAt: "2026-10-26T21:40:00+09:00"
  }
]
```

**틀린 문제 목록 (localStorage 키: `quiz-wrong`)**

```javascript
["h03", "s07", "g02"]   // 문제 id 배열. 데이터에 없는 id는 읽을 때 걸러낸다.
```

**게임 진행 상태 (메모리, 저장 안 함)**

```javascript
const state = {
  mode: null,          // "single" | "all" | "review"
  sessions: [],        // 과목 탭마다 따로 진행: { key, name, queue, index, score, picked }
                       //   queue: 출제 순서로 정리된 문제(각 항목에 category 포함)
                       //   picked: 현재 문제에서 고른 보기 인덱스, 아직 안 골랐으면 null
  current: 0,          // 지금 보고 있는 세션
  categoryScores: {},  // 과목별 맞힌 수
  categoryTotals: {},  // 과목별 푼 문제 수 (결과 계산 때 채움)
  startedAt: null,     // Date.now()
  endedAt: null,       // 마지막 문제에 답한 시각 (그만두면 그만둔 시각)
  quit: false,         // 중간에 그만뒀는지
  wrongAnswers: []     // 이번 판 오답 노트용
};
```

과목별 풀기와 틀린 문제 다시 풀기는 세션이 1개, 모든 과목 풀기는 과목마다 1개씩 4개다. 순위 정렬은 `records.sort((a, b) => b.score - a.score || a.elapsedSec - b.elapsedSec || a.playedAt.localeCompare(b.playedAt))` 한 줄로 처리한다. localStorage 읽기·쓰기는 try/catch로 감싸고, 실패하거나 값이 깨져 있으면 빈 배열로 시작한다.

## 6. 화면 구성

화면은 5개이며, 한 HTML 안에서 `section`을 숨기고 보이는 방식으로 전환한다. 시작·틀린 문제·순위 화면 위에는 '문제 풀기 / 틀린 문제(개수) / 순위표' 메뉴 탭이 있고, 퀴즈·결과 화면에서는 숨긴다.

| 화면 | 구성 요소 | 이동 |
| --- | --- | --- |
| 시작 | 게임 제목('QUIZ SHOW' 전구 간판), 안내 문구, 과목 버튼 4개, 문제 수 패널(과목을 누르면 열림: 슬라이드바, 눌러서 고치는 숫자, '○○ N문제 풀기' 버튼), '모든 과목 풀기' 버튼(과목별 문제 수와 총 문제 수 표시) | 풀기 → 퀴즈 |
| 퀴즈 | 맨 위: '그만 풀기' 버튼, 과목 탭 4개(모든 과목 풀기일 때만) · 상단: 과목명, 문제 번호(3 / 10), 진행 바, 현재 점수 · 중앙: 질문, 보기 버튼 4개 · 하단: 피드백 문구와 해설, '다음' 버튼(답한 뒤에만 보임, 과목 마지막 문제면 '다음 과목' 또는 '결과 보기') | 마지막 '결과 보기' → 결과, 그만 풀기 → 결과(푼 문제 없으면 시작) |
| 결과 | 총점(34 / 40, 85점), 푼 과목별 점수, 소요 시간(6:52), "전체 12개 기록 중 3위" 또는 순위 미기록 안내, 오답 노트(펼치기), '다시 하기', '틀린 문제', '순위표' 버튼 | 다시 하기 → 시작, 틀린 문제 → 틀린 문제, 순위표 → 순위 |
| 틀린 문제 | 안내 문구, 틀린 문제 목록(과목 표시 + 질문, 과목 순서), '틀린 문제 다시 풀기(N개)', '목록 비우기' | 다시 풀기 → 퀴즈 |
| 순위 | 안내 문구(정식 게임만 기록), 순위·점수·소요 시간·날짜 표(상위 10개), 방금 기록 강조, '처음으로', '기록 초기화' | 처음으로 → 시작 |

과목 버튼은 모바일에서 2×2, 데스크톱에서 1×4로 배치한다. 보기는 모든 폭에서 2×2로 배치하고, 칸마다 왼쪽에 원형 체크박스를 둔다. 데스크톱에서는 오른쪽 끝에 키보드 번호(1~4)를 작게 표시하고, 휴대폰 폭에서는 글자 자리를 위해 숨긴다. 퀴즈 화면의 과목 탭은 모든 폭에서 한 줄 4칸이다. 버튼 높이는 최소 48px로 해서 손가락으로 누르기 쉽게 한다.

**디자인 (1950~60년대 미국 TV 퀴즈 쇼 무대)**

- 색상: 어두운 브라운 `#3A241B`, 목재 브라운 `#70452F`, 버건디 `#781F2B`, 마키 골드 `#F4C94A`, 크림 `#F0DFC0`. 배경·패널은 브라운, 커튼·주요 버튼·오답은 버건디, 타이틀·전구·강조·선택·정답은 골드, 일반 글자는 크림.
- 배경: 화면 양옆에 짙은 버건디 벨벳 커튼. 가운데는 무늬 없는 브라운 그라데이션으로, 위쪽의 황동빛이 도는 밝은 브라운에서 아래로 갈수록 짙은 브라운이 된다. 시작 화면 외의 화면은 브라운 패널 위에 둔다.
- 메인 타이틀: 위가 넓게 뾰족하고 아래로 좁아지는 오각형 전구 간판(SVG). 버건디 틀에 노란 전구를 넉넉한 간격으로 두르고, 어두운 안쪽 면에 'QUIZ SHOW'를 슬랩 세리프(Arvo Bold) 채도 높은 노랑 글자 + 얇은 버건디 외곽선으로 쓴다. 글자 안에는 연노랑 전구 점을 듬성듬성 넣는다.
- 퀴즈 화면: 패널 맨 위 가운데에 큰 골드 간판(버건디 띠 + 골드 테두리)으로 `QUESTION 03` 형식의 과목 안 문제 번호를 표시하고, '그만 풀기'는 오른쪽(모바일은 윗줄 오른쪽)에 둔다. "3 / 10" 텍스트도 함께 둔다.
- 진행 바: 문제 풀이 화면의 붉은 포인트 색. 어두운 바탕 위에서 보이도록 왼쪽 짙은 버건디에서 진행한 끝의 밝은 빨강(`#C4142F`)으로 가로 그라데이션을 넣고 끝에 골드 선을 둔다.
- 실제 적용 색: 브라운은 원래 팔레트보다 채도를 조금 높이고(예: 패널 `#4F2C1C`, 선택지 `#63391F`), 버건디는 채도를 높이고 명도를 낮춘 `#6E0B19`를 쓴다(커튼 주름 `#2A040A`~`#5C0816`).
- 주요 버튼: 버건디 바탕 + 얇은 골드 테두리 + 크림 글자. 단, 퀴즈 화면의 '다음' 버튼과 시작 화면의 '○○ N문제 풀기' 버튼은 가독성을 위해 짙은 브라운 바탕 + 골드 테두리 + 골드 글자.
- 선택지: 정답 보기의 원형 체크박스는 초록, 고른 오답의 체크박스는 버건디로 채우고 둘 다 크림색 체크를 넣는다. 오답 자막은 반투명 버건디라 뒤의 브라운 패널이 비친다.
- 조명 효과: 화면 위 양쪽에서 타이틀 쪽으로 비추는 스포트라이트 빛줄기(9초 주기로 천천히 흔들림)와 타이틀 뒤 후광, 커튼 윗부분의 빛. 간판 전구는 빛 번짐이 있고 두 무리가 1.8초 주기로 번갈아 밝아진다. 패널 위쪽 조명, QUESTION 간판·진행 바·정답/오답 보기의 은은한 빛, 버튼에 마우스를 올리면 살짝 빛남. 깜빡임은 1초에 한 번보다 느리게 하고, '애니메이션 줄이기' 설정이면 움직임을 모두 끈다(빛 번짐은 고정으로 유지). 조명 때문에 글자 대비가 4.5:1 아래로 내려가지 않게 한다. 글꼴(Arvo, Yeon Sung)을 불러오지 못하면 Rockwell·Georgia 등 기본 serif로 표시한다.

**화면 문구 (영어 표기)**

메뉴·버튼·짧은 라벨과 틀린 문제·순위 화면 제목은 영어(주로 대문자)로 표시한다. 문제·보기·해설, 과목 이름, 정답/오답 피드백, 안내·설명 문장, 확인 창, 결과 화면의 내용(제목·점수·소요 시간·순위 문장·오답 노트)은 한국어로 둔다. 한국어 안내·설명 문장과 확인 창, 결과 문장은 미국 퀴즈쇼 사회자처럼 느낌표를 붙인 가볍고 유머러스한 존댓말로 쓴다(예: "놓친 문제들이 여기서 재도전을 기다리고 있어요! 맞히는 순간 목록에서 쏙 빠집니다!"). 안내해야 할 내용(순위 기록 조건, 되돌릴 수 없음 등)은 빠뜨리지 않는다. 이 문서의 다른 장에 나오는 한국어 이름은 아래 영어 표기로 화면에 나온다.

| 한국어 이름 | 화면 표기 |
| --- | --- |
| 문제 풀기 / 틀린 문제 / 순위표 (메뉴·버튼·제목) | QUIZ / WRONG ANSWERS / RANKING |
| 모든 과목 풀기 / ○○ N문제 풀기 | ALL SUBJECTS / PLAY ○○ · N QUESTIONS |
| 그만 풀기 / 다음 / 다음 과목 / 결과 보기 | QUIT / NEXT / NEXT SUBJECT / SEE RESULTS |
| 다시 하기 / 점수(퀴즈 화면) | PLAY AGAIN / SCORE |
| 틀린 문제 다시 풀기 / 목록 비우기 | RETRY WRONG ANSWERS / CLEAR LIST |
| 처음으로 / 기록 초기화 / 순위·점수·시간·날짜 / 방금 | HOME / RESET RECORDS / RANK·SCORE·TIME·DATE / NEW |

## 7. 비기능 요구사항

- 성능: 보기를 누른 뒤 피드백이 0.1초 안에 표시된다.
- 호환성: 360px 폭 모바일부터 1920px 데스크톱까지 가로 스크롤 없이 표시된다.
- 접근성: 정답/오답을 색만이 아니라 "정답!"/"오답" 문구와 ✓/✗ 아이콘으로도 구분한다. 보기는 키보드 1~4 키로 고르고 Enter로 다음 문제로 넘어간다. 글자 색은 배경 대비 4.5:1 이상으로 한다. 화면이 바뀌면 그 화면의 제목이나 질문으로 포커스를 옮긴다.
- 안정성: 문제 데이터가 과목별 10개가 아니거나, 보기가 4개가 아니거나, answer가 0~3 밖이거나, 한국사 문제에 `year`가 없으면 콘솔에 오류를 출력하고 시작 버튼을 막는다.
- 콘텐츠: 문제와 정답은 교과서·백과사전 기준으로 사실 확인하고, 시점에 따라 바뀌는 사실(인구 순위, 현직자 등)은 피한다.

## 8. 수용 기준

- [ ] 모든 과목 풀기(기본 설정)에서 정확히 40문제가 과목 순서대로, 각 10문제씩 나온다.
- [ ] 두 번 플레이했을 때 과학·지리·일반상식의 문제 순서와 모든 과목의 보기 순서가 달라진다.
- [ ] 한국사 문제는 항상 연도순으로 나온다. 문제 수를 줄여도 연도순이다.
- [ ] 오답을 고르면 고른 보기는 버건디 테두리와 "✗ 내 답", 실제 정답은 골드 테두리와 "✓ 정답"으로 표시되고 해설이 보인다.
- [ ] 답한 뒤에는 다른 보기를 눌러도 점수가 바뀌지 않는다.
- [ ] 결과 화면의 총점이 과목별 점수의 합과 같다.
- [ ] 과목 버튼을 누르면 슬라이드바가 기본값 10으로 열리고, 슬라이드바와 숫자 직접 입력 모두 문제 수를 바꾼다. 범위 밖 값은 1~10으로 맞춰진다.
- [ ] 모든 과목 풀기 중 다른 과목 탭으로 갔다가 돌아오면 풀던 문제(답한 상태 포함)에서 이어진다.
- [ ] 틀린 문제는 새로고침 후에도 틀린 문제 탭에 남아 있고, 다시 맞히면 목록에서 빠진다.
- [ ] 새로고침 후에도 순위표 기록이 남아 있다.
- [ ] 점수가 같은 두 기록은 소요 시간이 짧은 쪽이 위에 온다.
- [ ] 과목별 풀기, 문제 수를 바꾼 모든 과목 풀기, 틀린 문제 다시 풀기, 중간에 그만둔 판은 순위표에 기록되지 않는다.
- [ ] '그만 풀기'를 누르면 푼 문제만으로 결과(맞힌 수 / 푼 문제 수)가 나오고, 푼 문제가 없으면 시작 화면으로 돌아간다.

## 9. 개발 단계

1. 화면 뼈대: `index.html`, `style.css`로 화면 레이아웃과 화면 전환
2. 문제 데이터: `questions.js`에 40문제 작성 + 데이터 검증 함수
3. 퀴즈 진행: 셔플, 문제 표시, 답 선택, 즉시 피드백, 점수 집계 (`app.js`)
4. 결과와 순위: 결과 계산, localStorage 저장, 순위 정렬과 표시
5. 마무리: 반응형, 키보드 조작, P1 기능(과목 전환 안내, 오답 노트, 기록 초기화)
6. 테스트: 8장 수용 기준을 하나씩 체크
7. 확장: 과목별 풀기와 문제 수 선택, 한국사 시대순 출제, 과목 탭 이동, 틀린 문제 탭, 닉네임 입력 제거, 그만 풀기

**열린 질문**

- 과목당 문제가 10개라 문제 수 슬라이드바는 1~10까지만 움직인다. 문제를 더 추가하면 최대값이 자동으로 늘어나지만, 정식 게임(순위 기록) 기준을 과목당 10문제로 유지할지 함께 정해야 한다.
- 나중에 순위표를 여러 기기에서 공유하려면 서버나 Firebase 같은 외부 저장소가 필요하고, 그때는 닉네임 같은 사용자 구분이 다시 필요하다.
